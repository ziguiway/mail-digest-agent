# 交互设计预览

两份 HTML 均可独立在浏览器打开，使用示例数据，不访问真实邮箱、模型或飞书。它们用于比较展示方案，不是飞书客户端的实际渲染结果。

- [网页查询表格方案](query-table-designs.html)：聊天内简表、行动分组、表格与原文侧栏。用户已选择方案一，业务页面实现与验收见[聊天内简表记录](../verification/2026-11-05-query-tables.md)。另外两种布局保留为设计备选。
- [飞书推送方案](feishu-message-designs.html)：简洁通知、行动卡片、表格卡片。用户已选择方案一“简洁通知”，查询回复与每日摘要沿用 post 富文本，展示总览、重点事项、下一步及来源，合并普通通知。实现与检查见[简洁通知验收](../verification/2026-11-05-feishu-concise.md)。另两种卡片布局仍为设计备选。

页面顶部可切换方案，桌面窗口可切换手机预览宽度；表格、分组与依据展示支持相应的演示交互。预览中的邮件正文为设计拟写，不作为真实邮件或模型效果的证据。
