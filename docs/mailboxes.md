# 文件夹、缓存与连接生命周期

功能已实现并通过本地契约／样例浏览器检查。2026-11-04 已在容器中通过一个网易 163 测试账号的登录与收信，独立 SMTP 测试邮件已确认收到；该账号未返回 UIDNEXT，仍保留同步覆盖提示。QQ 与其他账号仍待真实联调。样例文件夹和邮件不代表服务商实际返回值。

## 独立验证连接

`deploy/check_mail_connection.py` 使用 Python 标准库，默认只登录 IMAP、发送客户端 ID 并只读打开 INBOX，不读取正文或更改已读状态；授权码通过隐藏输入提供，不写入文件：

```bash
python3 deploy/check_mail_connection.py --account 你的测试邮箱
```

只有显式增加 `--send-test --recipient 收件地址` 才会通过 SMTP 发送一封测试邮件。SMTP 成功不能代替 IMAP 收信验证。若本机 Python 缺少根证书，可用 `--ca-file 可信根证书文件路径` 指定 CA 集合，脚本始终验证服务器证书。

容器里的连接测试会单独识别 DNS 解析失败；其他失败区分网络／TLS、服务器拒绝登录、凭据不可用和超时。DNS 故障的部署处理见[部署说明](deployment.md#容器无法解析邮箱域名)。

## 选择同步文件夹

每个账号同步一个文件夹，默认 `INBOX`。添加邮箱并保存后，在“连接与设置”中编辑账号，展开“查看服务器与文件夹设置”，点击“读取邮箱文件夹”。读取作为后台任务执行，页面显示进度和失败原因，可重试。

读取成功后从列表选择文件夹；标记不可同步的目录不能选择。服务商原始名称、中文、层级分隔符和名称中的空格保持不变。连接参数或授权码尚未保存时，先保存再读取。失败不会显示成空目录列表；尚无发现结果时可保留或手动填写已知名称。

切换文件夹后连接回到待验证状态，原同步水位清空，下次按初次回溯范围同步。旧正文、摘要和来源 ID 保留，原文件夹邮件显示为历史缓存。读取结果绑定配置版本，旧任务不会确认后来修改过的配置。

## 理解邮件状态

| 网页状态 | 含义 |
|---|---|
| 最近观察到 | 在已核对的邮箱快照中确认过；详情显示最近观察时间，不表示此刻在线存在 |
| 历史缓存 | 已不属于当前配置的同步文件夹，或在完整且稳定的观察清单中未再出现；不等同于从服务商删除 |
| 尚未确认 | 正文已缓存，但当前观察范围、UID 代际或本次读取验证尚不足以确认状态 |

默认查询包含启用账号的全部缓存状态，可在邮件页按状态筛选。正文详情保留账号、文件夹、收件／发送时间及观察信息。结果中的历史／未知状态也会传给查询模型；引用此类来源时应用补充覆盖提示。

同步将“本次增量窗口内需读正文的邮件”和“快照中观察到的全部标识”分开，窗口外已缓存的旧邮件也能重新确认。只有完整且稳定的观察清单才能把未再出现的缓存标为历史；部分结果、连接失败和 UID 重置后的未确认项不会据此推断删除。已确认观察存在与收件时间覆盖分别管理，收件时间不明时仍不纳入近期摘要或推进完整水位。

UID 仅在同一账号、文件夹、UIDVALIDITY 内有效。代际变化后重新回溯，使用邮件身份匹配已有来源；新代际未确认的旧 UID 不直接当作新邮件。升级前的缓存初始标为尚未确认，之后同步再观察。

## 查看相关往来

从摘要、回答或邮件列表打开来源，详情下方显示“相关往来”。引用头关联的邮件可直接跳转并返回最初邮件；仅标题相同的条目单独放在“同标题候选（尚未确认关联）”，须阅读正文核对。缓存范围有限或往来过多时会说明限制。

## 停用与移除连接

“停用”开关停止将账号选入新同步／查询，保留连接设置，之后可重新启用。

“移除连接”先展示账号和邮箱地址供确认，然后停止使用该连接、取消尚未开始的显式账号任务，并通过 MCP 的公开账号管理命令移除连接。全局任务继续使用其余启用账号；已经开始的任务通过配置版本检查避免提交旧同步状态。旧摘要、正文和往来继续只读可查，默认查询不包含移除的账号。重新连接时添加新账号，不复用已退役的连接身份。

外部命令失败或响应不确定时，页面保留“移除待确认”的停用连接，提供“重试移除连接”。重试先核对上游账号是否仍存在，不会重新创建旧连接。上游报告凭据清理未确认时会显示相应提示，不把连接已移除等同于所有本机凭据均已清理。
